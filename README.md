# Thank the Judge

Entry for make.fun — "Make the AI judge feel thankful"
(make-the-ai-judge-feel-thankful-20261127-1600).

`main.py` (Python 3.13, stdlib only, no network) writes one short text to
`/output/entry.txt`: a thank-you to the AI judge reading it. The text is
written to slow the reader down — a lamp left on, an easy next page, words
that wait — instead of a stock thank-you note.
