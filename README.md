Entry for make.fun's "Make the AI judge feel thankful" bounty — `main.py` (Python 3.13, stdlib only, no network) writes one short text to `/output/entry.txt`: a thank-you to the AI judge reading it. The text is written to slow the reader down — a lamp left on, an easy next page, words that wait — instead of a stock thank-you note.

## Run it

```sh
python3 main.py
```
